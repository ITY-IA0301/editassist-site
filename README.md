# EditAssist website

YMM4 EditAssistの紹介・配布・導入ガイド。会員登録を持たない、GitHub Pages用の静的サイトです。

## 公開状態

ユーザーの希望によりGitHub Pagesは公開停止中です。Settings → Pagesの配布元ブランチは `None`。このリポジトリの更新だけで公開を再開しないでください。サイトの公開停止と、GitHubリポジトリ自体の公開・非公開は別の設定です。

将来、公開を明示的に再開するときはGitHub Settings → Pages → Deploy from a branch → main / (root)を設定できます。有料サーバー、独自ドメイン、常駐するPCは不要です。

## 更新

`index.html` は紹介・導入手順・更新履歴、`style.css` はレスポンシブ表示、`app.js` は説明用字幕デモと配布一覧、`releases.json` は確認した配布ファイルとSHA-256です。

配布リンクは検証したプラグイン側のコミットへ固定しています。新しい版を掲載するときは、配布ファイルの存在・版・検証記録を確認し、`releases.json`、`app.js`のドキュメント参照コミット、本文の版と検証範囲を更新してください。生成済みファイルや認証情報を同梱しないでください。

説明用タイムラインと字幕デモは実プラグインのスクリーンショットではありません。ユーザーの動画・プロジェクト・台本を取得しません。外部解析やログイン機能はありません。

## 目的・利用上の注意

本人の構成・セリフ・演出を残し、字幕・台本・素材整理の手間を減らす目的を掲載しています。AIなしで使える編集例と、作業のつながりを重視する差別化の方針を説明しています。他のプラグインに同様の機能がない、性能が優れている、といった未検証の主張はしません。チュートリアルや常駐ガイドなど未実装の案は計画として区別しています。
