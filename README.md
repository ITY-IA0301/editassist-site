# EditAssist website

YMM4 EditAssistの制作中の紹介・導入イメージ。会員登録を持たない、GitHub Pages用の静的サイトです。

## 公開状態

2026-10-11のユーザー指示により、「制作中！」の紹介サイトとしてGitHub Pagesで公開します。配布元は `main / (root)`。ダウンロード機能を無効にした状態を維持し、配布・販売の開始は別途明示的な指示を受けてから行います。サイトの公開と、プラグインリポジトリの公開・非公開は別の設定です。

プラグイン本体のリポジトリは非公開です。サイト側は「ダウンロード機能だけ無効」という指定に合わせ、公開用の紹介ページのソースを保持しています。サイトは「制作中」と表示し、一般配布・販売を停止しています。Webサイトは制作中の機能紹介として公開します。プラグインのソースや配布ファイルを公開用サイトへ含めないでください。

## 更新

`index.html` は紹介・導入手順・更新履歴、`style.css` はレスポンシブ表示、`app.js` は説明用字幕デモのみ、`releases.json` は確認した配布ファイルとSHA-256です。

一般配布は停止中です。本体・管理ツール・ソースZIP・旧版のリンクをHTMLから外し、配布一覧を取得・生成するJavaScriptも削除しています。JavaScript無効時にも配布リンクは出ません。`releases.json`は開発側の確認記録として保持し、サイトからは読み込みません。非公開のプラグインリポジトリへのドキュメント・Issueリンクも公開準備中の案内に置き換えています。

再配布を始める際は、ユーザーの明示的な指示を受けてから、購入・試用の条件、配布ファイル、検証記録と公開用サポート窓口を確認して導線を設定してください。生成済みファイルや認証情報を同梱しないでください。

説明用タイムラインと字幕デモは実プラグインのスクリーンショットではありません。ユーザーの動画・プロジェクト・台本を取得しません。外部解析やログイン機能はありません。

## 目的・利用上の注意

本人の構成・セリフ・演出を残し、字幕・台本・素材整理の手間を減らす目的を掲載しています。AIなしで使える編集例と、作業のつながりを重視する差別化の方針を説明しています。他のプラグインに同様の機能がない、性能が優れている、といった未検証の主張はしません。チュートリアルや常駐ガイドなど未実装の案は計画として区別しています。

利用上の注意にはバックアップの範囲、未検証事項、利用者と開発者の責任分担、YouTubeの収益化を保証しないこと、問題発生時の対応、機密情報の公開投稿を避ける案内を掲載しています。訴訟・損害賠償の請求リスクを免責の掲載だけで消せるとは説明しません。

現在は開発版であり、このサイトで有料販売は開始していません。本文は利用案内で、法的確認済みの販売規約・免責条項・テスター契約・秘密保持契約ではありません。返金条件や賠償範囲など正式な条件は未確定です。販売・テスト配布の前に、該当する規約と運用を専門家に確認してください。
